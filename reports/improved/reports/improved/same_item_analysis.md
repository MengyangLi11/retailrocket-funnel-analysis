# 改进02：同商品约束下的用户漏斗

## 统计口径

- 两种定义使用相同的1,399,102名用户。
- 均从用户首次被记录到的浏览开始计算24小时窗口。
- 均要求浏览、加购、购买按时间顺序发生。
- 新增约束：链路中的用户ID和商品ID均一致。
- 明细粒度为用户×商品，最终按用户去重统计。

## 结果对照

| 指标 | 允许跨商品 | 要求同商品 |
|---|---:|---:|
| 浏览用户 | 1,399,102 | 1,399,102 |
| 加购用户 | 28,195 | 26,125 |
| 购买用户 | 7,915 | 7,693 |
| 浏览到加购 | 2.0152% | 1.8673% |
| 加购到购买 | 28.0724% | 29.4469% |
| 浏览到购买 | 0.5657% | 0.5499% |

## 主要发现

- 同商品约束下，合格加购用户减少2,070人，
  占允许跨商品口径加购用户的7.34%。
- 合格购买用户减少222人，
  占允许跨商品口径购买用户的2.80%。
- 加购到购买比例升高，同时浏览到购买比例降低。
  这些变化来自链路定义及条件人群变化，不代表线上业务效果变化。

## 数据检查

- 覆盖浏览用户：1,399,102人。
- 不符合时间顺序或窗口的明细行数：0。

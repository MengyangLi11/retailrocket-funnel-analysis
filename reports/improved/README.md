# 改进01：24小时用户有序漏斗

## 分析目标

在原项目全期行为人数统计的基础上，加入时间顺序、
转化窗口和完整观察期，并逐项拆解统计口径变化的影响。

## 统计定义

- 按用户去重，每名用户从首次被记录到的浏览开始入组一次。
- 加购必须晚于首次浏览，购买必须晚于合格加购。
- 加购与购买均须在首次浏览后的24小时内完成，包含窗口终点。
- 相同时间戳不认定为存在先后顺序。
- 仅纳入首次浏览距离数据结束至少24小时的用户。
- 数据结束时间取最后一条事件时间。
- 本版允许跨商品，属于用户级漏斗。

## 口径对照

| 统计口径 | 浏览用户数 | 加购用户数 | 加购比例 |
|---|---:|---:|---:|

| 浏览与加购用户交集 | 1,404,179 | 34,401 | 2.4499% |
| 完整观察期人群，全期交集 | 1,399,102 | 34,312 | 2.4524% |
| 同一人群，全期按序 | 1,399,102 | 32,862 | 2.3488% |
| 同一人群，24小时按序 | 1,399,102 | 28,195 | 2.0152% |

## 主要发现

1. 原版加购人数包含3,321名没有浏览记录的用户。
2. 在完整观察期人群中，1,450名用户没有满足
   “晚于首次浏览”的加购记录。
3. 另有4,667名用户最早的后续加购超过24小时窗口。
4. 第3～5种口径使用相同用户集合，可分别观察
   时间顺序和窗口限制的影响。

上述差异反映统计定义的变化，不代表线上业务效果发生变化。
报表中的原版实验情景预估仍属于假设测算。
